# 目录迁移工具 — Windows 批量文件迁移

![Tech](https://img.shields.io/badge/Tech-Python%20%7C%20GUI-blue)
![Version](https://img.shields.io/badge/Version-v2.0.0-green)

## 📋 项目概述

Windows 桌面工具，用于批量迁移文件和目录，带有白名单保护和 GUI 界面。

**项目类型：** 桌面实用工具  
**版本：** v2.0.0  
**平台：** Windows

## ⚡ 核心功能

### 批量迁移
- 多目录同时迁移
- 文件完整性校验
- 进度实时显示
- 断点续传支持

### 安全保护
- **白名单保护：** 防止误迁移系统关键目录
- 目标路径验证
- 操作前确认机制
- 详细日志记录

### GUI 界面
- 直观的操作界面
- 拖拽式文件选择
- 实时进度展示
- 错误提示和处理

## 💡 技术亮点

### 安全机制
- 系统目录白名单检查
- 路径合法性验证

## 🎯 使用场景

- 系统盘清理迁移
- 大批量文件整理
- 用户数据迁移
- 磁盘空间管理

## 📝 白名单保护示例

工具会自动阻止以下危险操作：
- 迁移 `C:\Windows`
- 迁移 `C:\Program Files`
- 迁移系统用户目录
- 迁移注册表相关目录
