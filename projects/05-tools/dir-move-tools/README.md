## 📋 项目概览

Windows 桌面工具，用符号链接迁移 AppData 等大目录，带事务恢复与完整性校验。

**项目类型：** Windows 实用工具  
**开发周期：** 2024  
**项目状态：** 稳定版本

## ⚡ 核心特性

- 符号链接目录迁移
- 事务恢复机制
- 完整性校验
- Tkinter 图形界面
- PyInstaller 打包

## 🛠️ 技术栈

- Python 3.11+
- Tkinter
- PyInstaller
