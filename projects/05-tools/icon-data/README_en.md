## 📋 Project Overview

Powerful SVG icon library batch download tool supporting multiple mainstream icon libraries, equipped with GUI interface and embedded SVG icon system.

**Project Type:** Desktop Utility  
**Version:** v4.0.1

## ⚡ Core Features

### Multi-Platform Icon Library Support
- Multiple mainstream icon libraries
- Unified API interface
- Flexible source configuration
- Custom icon sources

### Batch Download
- Keyword search
- Category browsing
- Batch selection and download
- Custom filename rules

### Network Features
- Proxy support (HTTP/HTTPS/SOCKS5)
- Connectivity testing
- Resume from interruption
- Download queue management

### Index Generation
- Local icon indexing
- JSON/HTML index generation
- Preview page creation
- Search functionality integration
