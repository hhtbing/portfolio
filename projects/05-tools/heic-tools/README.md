# HEIC 工具 — Apple 图片格式查看器

![Tech](https://img.shields.io/badge/Tech-Python%20%7C%20Image%20Processing-orange)
![Platform](https://img.shields.io/badge/Platform-Windows-blue)

## 📋 项目概述

Windows 桌面工具，用于查看和转换来自 Apple 设备的 HEIC（高效图像容器）格式图片。

**项目类型：** 桌面实用工具  
**平台：** Windows

## ⚡ 核心功能

### HEIC 查看
- 直接打开 HEIC 文件
- 图片缩略图预览
- 全尺寸图片显示
- 图片元数据查看

### 格式转换
- HEIC 转 JPG
- HEIC 转 PNG
- 批量转换支持
- 质量参数可调

### 批量处理
- 文件夹批量转换
- 保持目录结构
- 转换进度显示
- 错误处理和跳过

## 💡 技术亮点

### 图像处理
- HEIC 解码算法
- 格式转换引擎
- 色彩空间管理
- 图片质量优化

### 用户体验
- 拖拽式操作
- 预览和转换一体
- 简洁的界面设计
- Windows 资源管理器集成

## 🛠️ 技术栈

- Python 3.x
- 图像处理库（PIL/Pillow）
- HEIC 解码库
- GUI 框架
- Windows 打包

## 📱 应用场景

- iPhone 照片查看
- iPad 图片转换
- macOS 图片兼容
- 跨平台图片分享

## 🎯 解决痛点

- Windows 原生不支持 HEIC 格式
- Apple 设备照片在 PC 上无法直接查看
- 避免安装复杂的编解码器
- 简化批量转换流程
