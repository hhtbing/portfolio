# USB Mic Mute — 麦克风静音控制器

![Tech](https://img.shields.io/badge/Tech-C%2B%2B%20%7C%20USB%20Protocol-red)
![Platform](https://img.shields.io/badge/Platform-Windows-blue)

## 📋 项目概述

Windows 桌面工具，通过硬件级 USB 控制实现麦克风静音，避免软件静音被应用绕过的问题。

**项目类型：** 系统工具  
**技术栈：** C++、USB 协议、Windows API

## ⚡ 核心功能

### 硬件级静音控制
- 直接 USB HID 设备控制
- 绕过操作系统音频层
- 应用程序无法解除静音
- 物理级别隐私保护

### 系统集成
- 系统托盘图标
- 快捷键支持
- 开机自启动
- 静音状态指示

### 设备管理
- 自动检测 USB 麦克风
- 多设备支持
- 设备热插拔处理
- 设备状态监控

## 💡 技术亮点

### 底层硬件控制
- USB HID 协议实现
- 直接设备通信

- 低级系统集成

### 安全性
- 管理员权限控制

## 🔒 隐私保护

### 解决的问题
- 某些应用程序会自动解除软件静音
- 会议软件可能绕过系统静音设置
- 恶意软件激活麦克风录音
- 隐私泄露风险

### 硬件级保护
- 物理断开麦克风供电或信号
- 应用层无法绕过
- 系统重启不受影响
- 可靠的隐私保护

## 📱 应用场景

- 远程会议静音控制
- 隐私敏感环境保护
- 防止误开麦克风
- 多人共享电脑场景
