## 📋 项目概述

批量转换工具，将文档和图片转换为语义化 Markdown 格式。

**项目类型：** 桌面实用工具  
**技术栈：** Python、OCR、Markdown 处理

## ⚡ 核心功能

### 多格式文档解析
- 图片文本识别
- 扫描文档 OCR
- 混合格式处理

### OCR 图片处理
- 文字识别（中英文）
- 表格识别
- 公式识别
- 图片提取
- 版面分析

### 语义 Markdown 生成
- 标题层级识别
- 列表自动识别
- 代码块识别
- 链接和图片处理

### 批量处理功能
- 文件夹批量转换
- 断点续传支持
- 进度保存和恢复
- 错误日志记录
- 结果预览
