![Tech](https://img.shields.io/badge/Tech-Python%20%7C%20OCR-orange)

## 📋 Project Overview

Batch conversion tool that transforms documents and images into semantic Markdown format.

**Project Type:** Desktop Utility  
**Tech Stack:** Python, OCR, Markdown Processing

## ⚡ Core Features

### Multi-Format Document Parsing
- Image text recognition
- Scanned document OCR
- Mixed format processing

### OCR Image Processing
- Text recognition (Chinese/English)
- Table recognition
- Formula recognition
- Image extraction
- Layout analysis

### Semantic Markdown Generation
- Heading level recognition
- Automatic list detection
- Code block identification
- Link and image processing

### Batch Processing
- Folder batch conversion
- Resume from interruption
- Progress saving and recovery
- Error logging
- Result preview

## 💡 Technical Highlights

- Semantic element extraction
