# AgentMeshOS — 自托管 AI Agent 平台 / AgentMeshOS — Self-Hosted AI Agent Platform

> 面向个人和小团队的自托管 AI Agent 运行时平台，把分散计算节点、模型能力、任务调度与成果交付组织成可追溯的工作链。

> Self-hosted AI agent runtime platform for individuals and small teams, organizing distributed compute nodes, model capabilities, task scheduling, and artifact delivery into a traceable work chain.
