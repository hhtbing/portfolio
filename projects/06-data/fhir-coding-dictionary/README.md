# FHIR Coding Dictionary — 医疗编码字典库

![Tech](https://img.shields.io/badge/Tech-FHIR%20%7C%20JSON%20Schema-blue)

## 📋 项目概述

符合 FHIR 标准的医疗编码字典库，提供 JSON Schema 验证和设备数据映射服务。

**项目类型：** 数据服务  
**版本：** v2.1.0+owlRD  
**版权：** WiseFido

## ⚡ 核心功能

### FHIR 标准合规
- 完整的 FHIR 资源定义
- 标准编码系统集成
- 术语服务支持
- 版本兼容性管理

### JSON Schema 验证
- 数据格式验证
- 类型检查
- 必填字段验证
- 自定义规则扩展

### 设备数据映射
- IoT 设备数据转换
- FHIR Observation 资源生成
- 单位换算和标准化
- 设备标识符管理

### RESTful API
- 编码查询接口
- 验证服务
- 映射配置
- 批量处理
