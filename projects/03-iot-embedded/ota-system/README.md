## 📋 项目概览

OTA-QL 是面向雷达设备的完整 OTA（空中升级）固件管理系统，支持 TCP 和 MQTT(S) 远程固件升级协议。系统包含服务端、Web 管理面板、桌面监控工具和 3D 雷达数据可视化演示模块。

**当前版本：** V20.1  
**项目类型：** 物联网管理系统  
**开发周期：** 2024-2026  
**项目状态：** 生产环境，管理 500+ 设备

---

## 🎯 系统组件

| 组件 | 技术栈 | 职责 |
|------|--------|------|
| **Go Server** | Go + cmux + MQTT | 设备网关、HTTPS API、MQTT broker、协议路由 |
| **Web 管理面板** | HTML/CSS/JS | 设备注册、固件管理、OTA 推送、用户认证 |
| **桌面监控工具** | Python + PySide6 | 实时设备监控、批量操作、日志追踪、虚拟滚动 |
| **3D 雷达演示** | Python + PyQt/Three.js | 雷达点云可视化、实时数据流展示、3D 目标追踪 |
| **Device Protocol** | TCP/MQTT + Protobuf | 双协议设备通信、自动切换和回退 |

## ⚡ 核心功能

### 1. 双协议 OTA 升级
- **TCP V2 协议**：直连设备，低延迟固件推送
- **MQTT(S) 协议**：云端中继，支持 NAT 穿透
- **自动协议切换**：根据网络环境智能选择协议
- **故障回退机制**：升级失败自动恢复到旧版本

### 2. 批量固件管理
- **批量推送**：支持最多 500 设备并发升级
- **分组管理**：按设备类型、固件版本、区域分组
- **进度追踪**：实时显示每台设备的升级进度
- **大批次排队**：超过并发上限自动排队等候

### 3. 桌面监控工具（Monitor Tool）
- **实时设备列表**：虚拟滚动技术支持大规模设备展示
- **OTA 进度可视化**：实时进度条、状态标识、完成百分比
- **实时日志流**：固件烧录日志实时推送和过滤
- **批量操作面板**：一键全选、批量推送、批量重启
- **设备健康检查**：连接状态、固件版本、异常告警

### 4. 3D 雷达数据可视化演示 :codex-annotation{index="9"}
- **点云实时渲染**：3D 空间中实时显示雷达点云数据
- **目标追踪可视化**：运动目标轨迹追踪和预测
- **多维数据展示**：距离、速度、角度、能量的多维可视化
- **回放与录制**：雷达数据录制和离线回放功能
- **性能优化**：支持高帧率实时数据流渲染

### 5. Web 管理面板
- **设备注册与管理**：设备列表、信息编辑、批量导入
- **固件版本控制**：版本上传、发布管理、历史版本追溯
- **OTA 推送接口**：Web 界面和 RESTful API 双通道
- **实时进度监控**：推送状态仪表板、设备状态统计
- **用户认证授权**：JWT 认证、角色权限、操作审计

### 6. 安全与防护
- **设备黑名单**：异常设备自动拦截和隔离
- **自动设备注销**：长期离线设备自动清理
- **拦截日志持久化**：完整的安全审计追踪
- **网关地址白名单**：只允许授权网关接入

## 💡 技术亮点

### 高并发架构
- **cmux 端口复用**：单端口同时支持 HTTPS、TCP、MQTT
- **协程池管理**：高效的 Go 协程资源管理
- **流控机制**：防止网络拥塞和设备过载
- **队列缓冲**：大批次任务自动排队和限流

### 协议灵活性
- **TCP/MQTT 双协议**：适配不同网络环境
- **Protobuf 序列化**：高效的二进制数据传输
- **协议自动切换**：网络故障时无感知切换
- **向后兼容**：支持多版本协议共存

### 生产级监控
- **桌面监控工具**：专业的设备管理和批量操作界面
- **虚拟滚动优化**：流畅展示数千台设备
- **实时数据流**：WebSocket 推送设备状态和日志
- **日志持久化**：完整的操作审计和故障追溯

### 数据可视化
- **3D 雷达演示**：直观展示雷达工作原理和数据质量
- **实时点云渲染**：高性能 3D 图形引擎
- **多维数据分析**：支持多种雷达数据格式解析

## 🛠️ 技术栈

**后端服务：**
- **Go** - 核心 OTA 服务和设备网关
- **cmux** - 端口复用和协议路由
- **MQTT Broker** - 消息队列和设备通信
- **Protobuf** - 高效序列化协议

**Web 前端：**
- **HTML/CSS/JavaScript** - 管理界面
- **WebSocket** - 实时数据推送
- **RESTful API** - 标准化接口

**桌面监控工具：**
- **Python 3.x** - 核心开发语言
- **PySide6 / PyQt6** - 跨平台桌面 UI 框架
- **虚拟滚动控件** - 大规模列表性能优化
- **异步 IO** - 非阻塞网络通信

**3D 可视化：**
- **Python + PyQt** - 桌面端 3D 渲染
- **Three.js** - Web 端 3D 图形
- **点云处理库** - 雷达数据解析和处理

**基础设施：**
- **Docker** - 容器化部署
- **systemd** - 服务守护和自动重启
- **SQLite / JSON** - 轻量级数据存储
