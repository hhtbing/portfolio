# OTA-QL — 雷达 OTA 管理系统 / OTA-QL — Radar OTA Management System

> 清澜雷达设备 TCP + MQTT(S) 远程固件升级全栈方案，包含 Go 服务端、Web 管理面板与桌面监控工具。

> Full-stack remote firmware upgrade solution for radar devices over TCP + MQTT(S), including a Go server, web panel and desktop monitoring tool.

- 类别 Category：IoT 与嵌入式 / IoT & Embedded
- 状态 Status：生产系统，从 V10 演进至 V20.1，覆盖可靠性、安全与体验优化。 / Production system evolved from V10 to V20.1 with reliability, security and UX improvements.
- 技术栈 Tech Stack：Go、cmux、Protobuf、MQTT、TCP、Python 3.11+、PySide6、PyInstaller、Docker、Nginx、GitHub Actions
