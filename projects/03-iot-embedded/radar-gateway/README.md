## 📋 项目概览

基于 ESP32 的网关系统，将 TI AWRL6844 雷达桥接到 Wi-Fi/TCP 网络，带 Web 管理界面。

**项目类型：** 嵌入式网关  
**开发周期：** 2023-2024  
**项目状态：** 已完成

## ⚡ 核心特性

- ESP32 主控，连接 TI 雷达
- Wi-Fi 网络桥接
- TCP 数据转发
- Web 管理界面
- 固件 OTA 升级

## 🛠️ 技术栈

- ESP32
- Node.js
- WebSocket
- UART 通信
