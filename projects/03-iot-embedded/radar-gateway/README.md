# AWRL6844 雷达网关系统 — 双 ESP32 架构物联网网关

## 📋 项目概述

本仓库是 AWRL6844EVM J5 雷达与 WT99P4C5-S1 J4 网关的主仓库。所有固件、Web 管理界面、部署脚本、发布包和文档均基于本仓库的 `main` 分支。

**项目类型：** 物联网网关系统  
**开发周期：** 2024-2026  
**芯片平台：** MediaTek MT7981（ESP32-P4 + ESP32-C5）

## ⚡ 核心功能

### 1. USB Host 集成
- **原生 USB Host 驱动**：ESP32-P4 直接控制雷达模块
- **XDS110 调试接口**：支持 TI 雷达固件烧录和调试
- **原始数据桥接**：无损转发雷达数据流

### 2. Wi-Fi 配网
- **AP 模式首次配置**：热点 `wisefidoXXXX`，默认 IP `192.168.4.1`
- **服务器地址设置**：支持域名和 IP 配置
- **配置持久化**：掉电保存配置参数

### 3. TCP 双通道桥接
- **雷达数据通道（端口 41002）**：高速数据流透传
- **CLI 控制通道（端口 41001）**：命令和状态查询
- **健康检查通道**：定期心跳和连接保活
- **原始字节转发**：网关层零解析，最大性能

### 4. Web 管理界面
- **设备注册与激活**：扫码绑定或手动添加
- **雷达复位控制**：远程重启雷达模块
- **配置队列管理**：批量配置下发和状态追踪
- **实时数据流展示**：WebSocket 实时推送雷达数据
- **数据包捕获工具**：网络抓包和协议调试

## 💡 技术亮点

### 双 ESP32 分工架构
- **清晰的职责分离**：P4 负责 USB Host，C5 负责网络通信
- **SDIO 高速总线**：芯片间数据传输带宽充足
- **模块化设计**：固件独立开发和升级

### AP 配网机制
- **零依赖首次配置**：无需外部工具，手机浏览器直接配置
- **引导式配置流程**：扫描 Wi-Fi、输入密码、设置服务器
- **配置成功自动重连**：保存后立即连接目标网络

### 原始数据透传
- **网关层不解析协议**：避免性能瓶颈和兼容性问题
- **直接字节转发**：保持数据完整性，最大化传输速率
- **协议无关设计**：支持任意雷达固件版本和数据格式

### 生产级稳定性
- **自动重连机制**：网络断线自动恢复
- **故障隔离**：USB 异常不影响 Wi-Fi，网络异常不影响 USB
- **看门狗保护**：固件死锁自动重启

## 🔗 设备连接与配置

### 首次设置流程

1. **硬件连接**
   - 给 WT99P4C5-S1 J1 Type-C 接口供电（5V）
   - 将 AWRL6844EVM J5 Micro-USB 连接到 J4 USB Host 接口
   - 观察网关板指示灯确认上电

2. **进入 AP 配网模式**
   - 上电时将 ESP32-C5 的 IO4 或 IO5 引脚接地
   - 或在正常运行时通过 CLI 命令触发 AP 模式

3. **连接配网热点**
   - 手机/电脑搜索 Wi-Fi 热点 `wisefidoXXXX`
   - 密码：无密码或默认密码（参考文档）

4. **Web 配置页面**
   - 打开浏览器访问 http://192.168.4.1
   - 扫描并选择目标 Wi-Fi 网络
   - 输入 Wi-Fi 密码
   - 设置服务器地址（默认：6844.yohan.fun）
   - 保存配置

5. **自动连接**
   - 配置成功后设备自动重启
   - 连接目标 Wi-Fi 网络
   - 建立 TCP 连接到服务器
   - 开始数据传输

### 正常运行状态

- **P4 职责**：USB Host 驱动加载 → 检测雷达模块 → 数据桥接到 SDIO
- **C5 职责**：连接 Wi-Fi → 建立 TCP 连接 → 双向数据透传
- **数据流**：雷达 → P4 → SDIO → C5 → TCP → 服务器 → 客户端
