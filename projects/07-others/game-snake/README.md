## 📋 项目概述

《沙曼的小蛇蛇》— 微信小游戏平台上的多蛇拼图消除游戏。

**项目类型：** 移动游戏  
**AppID：** wxaf093971e218837e  
**版本：** v2.0.0  
**游戏库：** 3.14.2

## 🎮 核心玩法

### 游戏机制
- **选择蛇** → **选择方向** → **逐格移动** → **出口消除**
- 多蛇交互（切尾、秒杀、阻挡）
- 通过创造空间和规划顺序解谜

### 游戏特色
- 3 秒上手，1 分钟沉浸
- 可爱简约视觉风格
- "Do-Re-Mi" 音效解压
- BGM 背景氛围
