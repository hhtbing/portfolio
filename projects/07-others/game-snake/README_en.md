## 🎮 Core Gameplay

### Game Mechanics
- **Select Snake** → **Choose Direction** → **Move Step-by-Step** → **Exit to Eliminate**
- Multi-snake interactions (tail cutting, instant kill, blocking)
- Solve puzzles by creating space and planning sequence

### Game Features
- 3 seconds to learn, 1 minute to immerse
- Cute minimalist visual style
- Decompression and healing experience
