# Owl Website — 官方网站与营销平台

![Tech](https://img.shields.io/badge/Tech-Node.js%20%7C%20Express%20%7C%20Docker-blue)
![Status](https://img.shields.io/badge/Status-Production-success)

## 📋 项目概述

WiseFido 官方网站和营销站点，配备 CMS 后台进行内容管理。

**项目类型：** 企业官网  
**技术栈：** Node.js、Express、Docker、Nginx

## ⚡ 核心功能

### 内容管理系统
- 静态页面服务
- Node/Express API 后端
- JWT 身份验证
- CMS 页面编辑器
- 页面版本保存/回滚
- 图片上传管理

### 运营功能
- 访问统计分析
- SMTP 邮件配置
- 管理员操作工作流
- 内容审核机制

### 部署架构
- Docker 容器化
- Nginx 反向代理
- Supervisor 进程管理
- API 速率限制
- 缓存控制策略
- 健康检查机制
- 日志收集系统

## 💡 技术亮点

### 前后端分离
- RESTful API 设计
- JWT 令牌认证
- 接口版本控制
- 统一错误处理

### 运维优化
- Docker 单容器部署
- Nginx 静态资源优化
- 进程自动重启
- 日志轮转管理

## 🛠️ 技术栈

**后端：**
- Node.js + Express

- 数据持久化

**部署：**
- Docker 容器化
