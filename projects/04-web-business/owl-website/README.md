## 📋 项目概述

企业级官方网站与营销平台,**不仅是静态页面展示**,而是包含完整后台管理系统的企业级 Web 应用。采用前后端分离架构,具备内容管理、用户系统、数据分析、运营工具等完整功能模块。

**项目类型:** 企业官网  
**架构模式:** 前后端分离 + 微服务  
**核心技术:** Node.js、Express、JWT、Docker、Nginx

## ⚡ 核心功能模块

### 1. 内容管理系统 (CMS)

**页面管理**
- 可视化页面编辑器,支持实时预览
- 页面模板系统,快速复用常用布局
- 版本控制系统,支持内容回滚与历史对比
- 草稿/发布/下线状态管理
- 多语言内容管理(中英双语)

**内容审核**
- 管理员审核工作流
- 内容变更历史追溯
- 敏感词过滤与检测
- 内容发布权限控制

**资源管理**
- 图片批量上传与压缩优化
- 文件分类与标签管理
- CDN 自动同步与加速
- 资源使用统计与清理

### 2. 用户认证与权限系统

**认证机制**
- JWT Token 无状态认证
- Refresh Token 自动续期
- 多设备登录管理
- 密码加密与安全策略

**权限管理**
- 基于角色的访问控制 (RBAC)
- 细粒度权限配置(查看/编辑/发布/删除)
- 管理员层级与权限继承
- 操作日志与审计追踪

### 3. 数据分析与统计

**访问分析**
- 页面访问量统计(PV/UV)
- 用户行为路径分析
- 流量来源与渠道分析
- 地域与设备分布统计

**运营报表**
- 自定义报表生成
- 数据可视化图表
- 定期报表自动发送
- 异常流量监控告警

### 4. 运营工具集

**邮件系统**
- SMTP 邮件服务配置
- 邮件模板管理
- 批量邮件发送
- 发送状态追踪

**工作流引擎**
- 内容发布审批流程
- 任务分配与跟踪
- 自动化任务调度
- 事件触发与响应

## 🛠️ 技术栈与实现

**后端:**
- **Node.js + Express** - RESTful API 服务
- **JWT** - 无状态身份验证
- **数据库** - 关系型数据持久化
- **Redis** - 会话缓存与热点数据

**部署:**
- **Docker** - 容器化部署
- **Nginx** - 反向代理与负载均衡
- **进程守护** - PM2 自动重启与日志管理
- **监控告警** - 日志分析与异常告警

**前端:**
- 前后端分离架构
- 响应式设计,移动端适配
- CDN 加速与资源优化

## 💡 技术亮点

### 架构设计
- **前后端分离**:清晰的职责边界,独立迭代与部署
- **微服务化**:模块解耦,按需扩展
- **无状态设计**:JWT 认证,易于水平扩展

### 性能优化
- **多层缓存**:Nginx 静态缓存 + Redis 数据缓存
- **CDN 加速**:全球内容分发网络
- **资源优化**:图片压缩、代码分割、懒加载

### 安全保障
- **JWT 鉴权**:防止 CSRF 攻击
- **权限控制**:细粒度的 RBAC 权限系统
- **操作审计**:完整的日志追溯与审计
