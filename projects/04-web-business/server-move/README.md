# Server Move — 服务器迁移方案 / Server Move — Server Migration Solutions

> 为多个独立网站迁移组织的配置仓库，每个站点拥有独立容器、反向代理、数据目录与验证记录。

> Configuration repository organized for multiple independent website migrations; each site owns its container, reverse proxy, data directory and verification notes.

- 类别 Category：Web 与业务系统 / Web & Business
- 状态 Status：强调迁移可验证、可回滚，避免破坏现有服务。 / Emphasizes verifiable, rollback-safe migration without disrupting existing services.
- 技术栈 Tech Stack：Docker、Docker Compose、Nginx、SSL/TLS、Shell
